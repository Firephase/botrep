# Telegram → YouGile Bot

Бот для управления Kanban-доской YouGile через Telegram.
Понимает свободный текст, голосовые сообщения и фотографии.

---

## Быстрый старт

```bash
cp .env.example .env   # заполни переменные
docker compose up -d --build
```

## Команды бота

### Базовые

| Команда | Описание |
|---|---|
| `/start` | Приветствие и краткая справка |
| `/help` | Полный список форматов и статусов |
| `/sync` | Принудительная синхронизация с YouGile (обновить кэш кадров) |
| `/status` | Показать все колонки текущей доски |
| `/myid` | Показать свой User ID и Chat ID (нужно для `REPORT_CHAT_ID`) |
| `/cancel` | Отменить текущее ожидание ввода |
| `/report` | Немедленно выслать сводку действий за сегодня |

### Задачи

| Команда | Описание |
|---|---|
| `/add [название]` | Создать задачу в «Бэклоге». Без аргумента — спросит название |
| `/delete <кадр>` | Удалить задачу (мягкое удаление). Показывает чеклист подтверждения |

### Редактирование задачи

| Команда | Описание |
|---|---|
| `/comment <кадр> [текст]` | Добавить комментарий в чат задачи. Без текста — спросит |
| `/desc <кадр> [текст]` | Изменить описание задачи. Без текста — спросит |
| `/cleardesc <кадр>` | Очистить описание задачи |
| `/messages <кадр>` | Показать последние 15 сообщений чата задачи с кнопками 🗑 удаления |
| `/assign <кадр>` | Назначить исполнителя (клавиатура со списком пользователей) |
| `/deadline <кадр> <ДД.ММ.ГГГГ>` | Установить дедлайн |

### ИИ

| Команда | Описание |
|---|---|
| `/qwen <текст>` | Разбор текста через Qwen LLM — находит все команды, показывает чеклист |

## Свободный текст (без команды)

Бот разбирает обычные сообщения автоматически.
Если найдено **2 и более команд** — показывает чеклист с галочками ✅/⬜, ты выбираешь нужные и жмёшь **Выполнить**.

### Форматы кадров

```
кадр 5          к5           К5
кадры 1-15      кадры 1, 3, 7
кадр с 10 по 20
шот 3           сцена 2
```

### Распознаваемые статусы

| Колонка YouGile | Слова-триггеры |
|---|---|
| **Бэклог** | бэклог, запланировано, в очереди |
| **В работе** | в работе, взял, взяла, делаю, делаем, начал, работаю |
| **У заказчика** | заказчику, клиенту, у заказчика, отправил заказчику, ушло клиенту |
| **На правках** | правки, поправить, исправить, надо изменить, на доработке |
| **Готово** | готово, апрув, approved, финал, сдано |
| **На внутренней проверке** | на проверку, чекните, проверка, внутренняя проверка |
| **На цветокоре** | цветокор, цветокоррекция, на цветокоре |
| **На анимации** | анимация, анимирую, анимировать, на анимации |

### Примеры

```
Кадры 1-5 у заказчика
К3, к4, к11 в бэклог
Кадр 7 на правках
Удалить кадр 7
Добавить кадр 15
Комментарий к кадру 5: уточни детали
Описание кадра 3: переделать монтаж

# Несколько команд → чеклист:
к1-5 у заказчика, к6-10 на правках, к11 удали
Кадр 5 апрув, кадры 6-10 в работе, кадр 3 правки
```

## Голосовые сообщения

Требуется `GROQ_API_KEY`.

- Речь распознаётся через Groq Whisper (русский).
- Если в речи слышно **«Квен»** / **«Qwen»** — запрос передаётся Qwen LLM, который найдёт все команды и покажет чеклист.
- Иначе — текст обрабатывается обычным парсером.

## Фотографии

- Отправь фото с подписью, содержащей номер кадра (`Кадр 5`) — фото загрузится в YouGile и ссылка появится в чате задачи.
- Без подписи — бот спросит номер кадра.

## Как добавить или изменить статусы

Открой **`parser.py`**, словарь `STATUS_ALIASES`:

```python
STATUS_ALIASES: dict[str, list[str]] = {
    "Бэклог": ["бэклог", "запланировано", "в очереди"],
    "В работе": ["в работе", "взял", ...],
    ...
}
```

- **Ключ** — точное название колонки в YouGile (регистр важен).
- **Список** — слова/фразы, которые бот распознаёт как этот статус.

Добавить новую колонку:
```python
"На монтаже": ["монтаж", "монтирую", "на монтаже"],
```

Добавить синоним к существующей:
```python
"Готово": ["готово", "апрув", "approved", "ок", "окей", "принято"],
```

После изменений: `docker compose up -d --build`.

## Как добавить слова-триггеры для действий

В **`parser.py`**:

```python
_DELETE_WORDS   = ["удалить", "удали", "убрать", ...]   # удаление задачи
_ADD_WORDS      = ["добавить", "добавь", "создать", ...] # создание задачи
_COMMENT_WORDS  = ["комментарий", "заметка"]             # добавить комментарий
_DESCRIBE_WORDS = ["описание", "изменить описание"]      # изменить описание
```

Просто добавь нужное слово в список.

## Как изменить время ежедневной сводки

В `.env`:
```env
REPORT_CHAT_ID=123456789   # твой Telegram User ID (из /myid)
REPORT_TIME=09:00          # время в UTC
```

Перезапуск: `docker compose up -d`.

## Структура проекта

```
handlers.py      — Telegram-обработчики, все команды и колбэки
parser.py        — разбор свободного текста → список ParsedEvent
sync_engine.py   — бизнес-логика: перемещение, создание, удаление
yougile.py       — HTTP-клиент YouGile REST API v2
llm.py           — Qwen LLM клиент (мульти-команды из одного сообщения)
stt.py           — Groq Whisper STT клиент
database.py      — SQLite: кэш задач, лог действий
config.py        — конфигурация из переменных окружения
main.py          — точка входа, сборка приложения
```
